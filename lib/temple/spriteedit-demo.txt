TempleOS-style sprite element-list demo.
Edit the sprites with:  temple/spriteedit lib/temple/spriteedit-demo.txt face
The sprite is an ordered list of drawing elements, one per line, replayed in
order -- the same vocabulary as lib/temple/sprites/*.spr.

.SPRITE face

circle 0 0 20
floodfill 0 0
color 0
thick 2
circle -7 -7 2
circle 7 -7 2
bspline2 3 -9 5 0 0 13 0 9 5 0
.ENDSPRITE
