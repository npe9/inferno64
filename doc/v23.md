# Vanadium Core on Inferno64

This branch ports the core ideas of [Vanadium](https://github.com/vanadium)
([v.io](https://v.io)) — secure RPC, principals, and blessings — to Inferno Limbo.

Upstream reference tree (Go): https://github.com/vanadium/core  
License: see `appl/lib/v23/LICENSE` (Vanadium Authors, BSD-style).

## What is ported

| Vanadium (`v.io/v23`) | Inferno Limbo |
| --- | --- |
| `security.Principal` / Bless / BlessSelf | `V23security->Principal` |
| Blessings (certificate chains) | `Blessings` + Keyring signatures |
| Caveats (const / expiry) | `unconstrained()`, `expiry()` |
| Blessing patterns (`…`, `:`) | `pattern_match` / `authorize` |
| RPC client/server + blessing handshake | `V23rpc` over `dial` + `msgio` |
| Fortune example | `v23/fortuned`, `v23/fortune` |

This is an Inferno-native encoding (not wire-compatible with Go VOM).

## Layout

- `module/v23.m` — module interfaces
- `appl/lib/v23/security.b`, `rpc.b` — implementation → `/dis/lib/v23/`
- `appl/cmd/v23/` — `principal`, `selftest`, `fortune`, `fortuned` → `/dis/v23/`

## Build

```
cd appl/lib/v23 && mk install
cd appl/cmd/v23 && mk install
```

Requires an emu with a working `$Keyring` builtin. Keyring must
`fmtinstall('B', big64conv)` so `pktostr`/`certtostr` round-trip (see
`libinterp/keyring.c`).

## Quick test

```
emu /dis/v23/selftest.dis
```

Fortune (two windows / processes):

```
emu /dis/v23/fortuned.dis -a tcp!*!3242
emu /dis/v23/fortune.dis -a tcp!127.0.0.1!3242 get
```
